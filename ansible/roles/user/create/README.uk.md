# Ansible Role: user/create

Роль створює локального користувача Linux із заданими параметрами. Підтримує використання наявної первинної групи або автоматичне створення нової.

## Параметри

| Параметр | Типово | Призначення |
|---|---|---|
| `user_create_name` | Обов'язковий | Ім'я користувача |
| `user_create_uid` | Обов'язковий | UID користувача |
| `user_create_home` | Обов'язковий | Домашній каталог |
| `user_create_group` | `""` | Назва первинної групи |
| `user_create_gid` | `null` | GID первинної групи |
| `user_create_shell` | `/usr/sbin/nologin` | Оболонка |
| `user_create_comment` | `""` | Поле GECOS |
| `user_create_system` | `true` | Створювати системний обліковий запис |
| `user_create_home_enabled` | `false` | Створювати домашній каталог |

## Логіка визначення групи

1. **Не задано group і gid:** використовуються `group = username`, `gid = uid`.
2. **Задано лише gid:** використовується наявна група з таким GID; якщо її немає — створюється група з назвою username.
3. **Задано лише group:** використовується GID наявної групи; якщо її немає — створюється група з `gid = uid`.
4. **Задано group і gid:** перевіряється відповідність; якщо обидва ідентифікатори вільні — створюється група.

Конфлікти назв і GID спричиняють помилку.

## Ідемпотентність

- Наявний користувач із відповідними параметрами не змінюється.
- Невідповідність UID, GID, GECOS, home або shell спричиняє помилку.
- Новий користувач створюється лише після перевірки параметрів та конфліктів.
- Наявні групи не модифікуються.

## Особливості

- Конфлікти перевіряються через NSS, включно з LDAP.
- Роль створює лише локальні облікові записи.
- Дозволяється використовувати наявні LDAP-групи як первинні.
- Не керує паролями та додатковими групами.
- Не перевіряє фактичний стан домашнього каталогу.
- Параметри `system` та `create_home` застосовуються лише під час створення.
- Для виконання потрібні права адміністратора та підтримка `getent -s files`.
